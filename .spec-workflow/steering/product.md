# Product Overview

## Product Purpose
Alist-MikananiRss 是一个自动化的动漫下载管理系统，旨在解决动漫爱好者手动追踪和下载最新番剧更新的痛点。系统通过监控蜜柑计划等RSS订阅源，自动获取动漫更新并通过Alist集成的下载器将文件下载到云存储，同时结合AI技术实现智能重命名，为媒体服务器提供更好的兼容性。

## Target Users
### 主要用户群体
1. **动漫爱好者**：定期追看新番，希望自动化下载流程的用户
2. **媒体服务器管理者**：使用Emby、Plex、Jellyfin等媒体服务器，需要规范文件命名的用户
3. **云存储用户**：使用115网盘、OneDrive等云存储服务，希望离线下载到云端的用户
4. **技术爱好者**：喜欢折腾自动化工具，拥有Alist部署经验的用户

### 用户痛点
- 手动检查RSS源更新耗时费力
- 文件命名不规范导致媒体服务器无法识别
- 多个RSS源管理复杂
- 缺乏统一的下载状态通知机制
- WebDAV嵌套目录结构问题影响文件访问

## Key Features

### 1. 自动化RSS监控
- **多源支持**：支持蜜柑计划、动漫花园、ACG.RIP等多个RSS源
- **智能过滤**：基于正则表达式的灵活过滤系统，支持排除合集内容
- **定时检查**：可配置的检查间隔，确保及时获取更新

### 2. 云存储集成下载
- **多下载器支持**：qBittorrent、Aria2、115 Open
- **种子转换**：自动将种子文件转换为磁力链接
- **路径管理**：智能的下载路径构建和文件组织

### 3. AI智能重命名
- **多LLM支持**：OpenAI、Google Gemini、DeepSeek等AI模型
- **结构化输出**：JSON格式的标准化重命名结果
- **自定义映射**：支持用户自定义重命名规则映射

### 4. WebDAV修复工具
- **嵌套目录修复**：自动修复WebDAV嵌套目录结构问题
- **冲突处理**：支持跳过、重命名、覆盖等多种冲突处理策略
- **递归扫描**：深度扫描目录结构，全面修复问题

### 5. 多渠道通知
- **即时通知**：Telegram、PushPlus等多种通知方式
- **批量通知**：支持批量处理完成后统一通知
- **详细状态**：提供下载进度、完成状态等详细信息

### 6. Telegram机器人助手
- **远程管理**：通过Telegram管理下载任务
- **状态查询**：实时查看下载进度和RSS更新状态
- **配置管理**：修改部分配置项，查看运行日志

## Product Principles

### 1. 自动化优先
**原则**：最大化减少用户手动操作，提供全自动化的使用体验
**实现**：从RSS监控到文件重命名的完整自动化流程

### 2. 配置灵活性
**原则**：提供丰富的配置选项，满足不同用户的个性化需求
**实现**：模块化的配置系统，支持多种RSS源、下载器、通知方式

### 3. 可扩展性
**原则**：采用模块化设计，便于添加新的RSS源、下载器和功能
**实现**：插件化的RSS解析器、LLM提供商和通知机器人

### 4. 稳定性
**原则**：确保系统长期稳定运行，提供可靠的下载管理服务
**实现**：完善的错误处理、日志记录和恢复机制

### 5. 用户友好
**原则**：提供清晰的文档、直观的配置和有用的错误信息
**实现**：详细的配置说明、丰富的命令行选项和Telegram助手
